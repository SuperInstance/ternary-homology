# ternary-homology

Simplicial homology computation over Z₃ — chain complexes, boundary operators, Betti numbers, and Euler characteristic with ternary coefficients.

## Background

Algebraic topology studies the shape of spaces through algebraic invariants. **Simplicial homology** is a computable form of this theory: given a simplicial complex (a set of points, edges, triangles, tetrahedra, and higher-dimensional simplices glued together), we construct chain groups Cₖ (free abelian groups generated by k-simplices) and boundary operators ∂ₖ : Cₖ → Cₖ₋₁ that map each simplex to its oriented boundary. The key insight is that ∂ₖ₋₁ ∘ ∂ₖ = 0 (the boundary of a boundary is empty), creating a chain complex.

The **homology groups** Hₖ = ker(∂ₖ) / im(∂ₖ₊₁) capture "holes" in the space: H₀ counts connected components, H₁ counts tunnels (loops you can't fill), H₂ counts voids (cavities you can trap gas in). The **Betti numbers** βₖ = dim(Hₖ) are topological invariants—they don't change under continuous deformation.

Classically, homology is computed over ℤ (integers) or ℤ₂ (integers mod 2). Computing over **Z₃** (integers mod 3) is significant because Z₃ is a field, which means Smith Normal Form reduces to simple Gaussian elimination. More importantly, Z₃ detects **3-torsion**: elements that are non-trivial but become trivial when multiplied by 3. A space with Z₃ torsion has structural features invisible to Z₂ homology.

The **Euler characteristic** χ = Σₖ (−1)ᵏ · fₖ (where fₖ is the number of k-simplices) is a topological invariant equal to Σₖ (−1)ᵏβₖ. For a tetrahedron: χ = 4 − 6 + 4 = 2; for a circle: χ = n − n = 0.

## How It Works

### Architecture

The crate provides three main abstractions:

1. **`Simplex`**: A sorted set of vertex indices with dimension `dim = |vertices| − 1`. Supports construction helpers (`vertex`, `edge`, `triangle`, `tetrahedron`) and a `boundary()` method returning oriented (k−1)-faces with alternating signs ±1.

2. **`SimplicialComplex`**: A collection of simplices. Provides `skeleton(k)` to extract k-dimensional simplices, `f_vector()` for simplex counts by dimension, `euler_characteristic()` for χ, and `boundary_matrix(k)` for the Z₃ boundary operator.

3. **Preset builders**: `tetrahedron()`, `solid_triangle()`, `hollow_triangle()`, `circle_graph(n)` for common topological spaces.

### Boundary Matrix Computation

For dimension k, the boundary matrix B has rows indexed by (k−1)-simplices and columns by k-simplices. Entry B[i][j] = sign of the i-th (k−1)-face in the boundary of the j-th k-simplex, reduced mod 3 (with 2 mapped to −1 for the ternary representation).

### Betti Number Computation

The implementation uses a simplified rank-based approach: βₖ ≈ dim(Cₖ) − rank(∂ₖ) − rank(∂ₖ₊₁), where rank is estimated by counting non-zero columns in the boundary matrix. This is an approximation that works well for small complexes but may underestimate Betti numbers for larger ones due to rank estimation imprecision.

### Torsion Detection

`has_torsion(complex, k)` checks whether the boundary matrix at dimension k+1 contains entries ≡ 2 (i.e., −1) mod 3, indicating potential Z₃ torsion elements.

## Impact of Ternary {-1, 0, +1}

Computing homology over Z₃ with ternary coefficients {-1, 0, +1} provides:

- **Torsion Detection**: Z₂ homology cannot detect odd torsion. Z₃ reveals 3-torsion elements that indicate spaces with three-fold symmetric structure.
- **Field Arithmetic**: Z₃ is a field, so Gaussian elimination works directly without the complication of Smith Normal Form over ℤ.
- **Compact Representation**: Each coefficient is a single trit (ternary digit), using minimal storage for chain groups.
- **Natural Orientation**: The ±1 representation matches the geometric intuition of boundary orientation—edges point "left" or "right," triangles wind "clockwise" or "counterclockwise."

## Use Cases

1. **Topological Data Analysis (TDA)**: Build Vietoris-Rips complexes from point cloud data and compute Betti numbers to detect the "shape" of data—clusters (H₀), loops (H₁), voids (H₂). The Z₃ computation detects torsion invisible to standard Z₂ pipelines.

2. **Network Topology Analysis**: Model a communication network as a simplicial complex (edges = links, triangles = redundant paths, tetrahedra = fully connected groups). Betti numbers reveal connectivity robustness and routing holes.

3. **Mesh Validation**: In GPU graphics and finite element analysis, verify that mesh structures have expected topology (e.g., a solid mesh should have χ = 2 and H₁ = 0). Unexpected Betti numbers indicate mesh defects.

4. **Sensor Network Coverage**: Model sensor coverage regions as simplices. Homology computation reveals coverage holes (H₁ ≠ 0) and disconnected regions (H₀ > 1).

5. **Configuration Space Analysis**: In robotics, the configuration space of linked joints can be analyzed topologically. Non-trivial H₁ indicates non-contractible loops—paths that can't be continuously deformed to a point, implying motion constraints.

## Open Questions

1. **Rank Estimation Accuracy**: The current Betti number computation uses a simplified column-counting heuristic for matrix rank. For larger complexes, this may underestimate Betti numbers. Implementing proper Z₃ Gaussian elimination would improve accuracy—what is the computational cost?

2. **Persistent Homology Extension**: The current crate computes homology at a single scale. Extending to persistent homology (tracking Betti numbers across a filtration of complexes) would enable TDA applications. How should the ternary coefficient structure interact with the filtration parameter?

3. **Z₃ vs Z₂ vs Z Empirical Comparison**: For practical topological data analysis, how often does Z₃ detect features that Z₂ misses? A benchmark study on standard TDA datasets would quantify the value of ternary homology.
